# NonCanonical-NGlyco Pipeline

## Expanding the N-glycoproteome: Identification of non-canonical N-glycosylation sites in existing datasets using a bioinformatics approach

[![Python](https://img.shields.io/badge/Python-3.10+-blue.svg)]()
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)]()

## Overview

This repository contains the Python scripts, reference files, and example datasets used in our study for the identification and characterization of canonical and non-canonical **N-glycosylation sites** using **pGlyco3.1**.

The workflow includes:

- Generation of a modified **J-X-V** proteome database
- Construction of an entrapment proteome for specificity assessment
- Post-processing and filtering of pGlyco3.1 search results
- Identification of canonical (**N-X-S/T**) and non-canonical (**N-X-C** and **N-X-V**) glycopeptides
- UniProt-based glycosylation site annotation
- Entrapment analysis for evaluating false-positive identifications

# Computational Workflow

## Step 1 — Database Generation

The human UniProt reference proteome is modified by replacing every **N-X-V** motif with **J-X-V**.

```
Human UniProt Proteome
        │
        ▼
create_JXV_database.py
        │
        ▼
Modified J-X-V FASTA
```

The modified FASTA is subsequently used for pGlyco3.1 database searching.

---

## Step 2 — pGlyco3.1 Database Search

The modified FASTA database is searched using **pGlyco3.1** to identify canonical and non-canonical glycopeptides.

```
Modified FASTA
        │
        ▼
pGlyco3.1
        │
        ▼
CSV Results
```

---

## Step 3 — Post-processing

The pGlyco3.1 output files are processed to identify and annotate glycopeptides.

```
pGlyco3 Results
        │
        ▼
filter_pglyco_results.py
        │
        ▼
Canonical N-X-S/T
Non-canonical N-X-C
Non-canonical N-X-V
        │
        ▼
UniProt Annotation
```

The script performs:

- Protein accession cleaning
- Glycopeptide deduplication
- Motif identification
- Canonical/non-canonical classification
- UniProt annotation
- Excel report generation

---

## Step 4 — Entrapment Analysis

To evaluate the specificity of non-canonical identifications, an entrapment database is generated by replacing biologically implausible sequons with placeholder residue **J**.

```
Human UniProt Proteome
        │
        ▼
create_entrapment_database.py
        │
        ▼
Entrapment FASTA
        │
        ▼
pGlyco3.1 Search
        │
        ▼
entrapment_analysis.py
        │
        ▼
Entrapment Reports
```

The entrapment pipeline performs:

- Batch processing of multiple datasets
- Protein accession cleaning
- ProSite expansion
- Glycopeptide deduplication
- Detection of all J-X-* motifs
- Canonical vs entrapment motif classification
- Amino acid-specific summaries
- Motif-specific reports
- Excel report generation

# Scripts

## database_generation/create_JXV_database.py

Generates a modified human proteome by replacing all **N-X-V** sequons with **J-X-V**.

### Input

- Human UniProt proteome FASTA

### Output

- `modified_proteome_JXV.fasta`

---

## database_generation/create_entrapment_database.py

Generates an entrapment proteome by replacing biologically implausible sequons with placeholder residue **J**.

### Input

- Human UniProt proteome FASTA

### Outputs

- `modified_proteome_entrapment.fasta`
- `changes_log_entrapment.txt`

---

## post_processing/filter_pglyco_results.py

Processes pGlyco3.1 search results and produces filtered canonical and non-canonical glycopeptide reports.

Major functions include:

- Protein accession cleaning
- Duplicate removal
- Motif identification
- UniProt annotation
- Excel report generation

---

## entrapment_analysis/entrapment_analysis.py

Processes pGlyco3.1 search results generated using the entrapment database.

Outputs include:

- Overall summary
- Amino acid summary
- Motif-specific worksheets
- Single entrapment peptides
- Multiple motif peptides
